# Territory importance scoring (PALIMPSEST RUBRIC v1.0)

An entertainment exercise: the maximal defensible ("lawyered") all-time peak share of world population and GDP for county-scale territories.

- `RUBRIC.md` — the rubric, verbatim.
- `CONVENTIONS.md` — operating conventions adopted on top of the rubric (interpolation, deep floors, polygon choice, vetoes).
- `palimpsest.py` — floor / share / band calculator so every unit uses the same arithmetic.
- `GALLERY.md` — anchor gallery (seed pegs, provisional reference points, finalized units).
- `units/` — one file per finalized unit, in the output schema.
